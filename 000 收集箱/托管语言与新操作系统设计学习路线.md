# 正文

基于 [[000 收集箱/新操作系统设计|新操作系统设计]] 的核心理念——用安全托管语言从底层构建系统、减少虚拟内存和硬件隔离等抽象层——设计一门适合该系统的编程语言，需要同时研究操作系统架构、类型系统、运行时、编译器后端与并发模型五个方向。

## 核心理念

- 抛弃历史包袱，在现代硬件上重新思考软件技术栈。
- 用类型系统和运行时提供隔离，替代复杂的虚拟内存管理与硬件保护模式。
- 所有应用可在同一地址空间运行，以极低成本完成上下文切换和进程间通信。
- 托管并不意味着 overhead，而是更简单、更安全、更可靠的系统。

## 托管操作系统

托管操作系统的核心思想是以类型安全的托管语言构建整个软件栈，用类型系统与运行时取代硬件页保护来实现进程隔离。所有应用运行在同一地址空间，上下文切换与进程间通信的成本因此大幅降低。

### Midori

Midori 是微软研发的托管操作系统，由百余人耗时八年完成。其设计建立在三个安全之上：类型安全、内存安全、并发安全。三者叠加后，进程隔离不再依赖硬件页保护。Midori 在多个基准上快于原生 C#，关键在于提前编译、边界检查消除与反馈导向优化。Joe Duffy 的博客系列是该项目最详尽的公开资料。

### Singularity

Singularity 是 Midori 的前身，由微软研究院开发。其核心是软件隔离进程（SIP）模型：进程间不靠硬件隔离，而靠类型安全语言与基于契约的 channel 通信。Sing# 是为该项目扩展的 C# 方言，引入了类型化 channel 用于消息传递。

## 托管语言的构成

### 类型系统

类型系统是托管语言的安全基础。类型安全的形式化表述是 progress 与 preservation 两条性质。类型系统设计需研究简单类型 lambda 演算、子类型、多态、递归类型、线性类型、所有权与能力。

### 垃圾回收

托管语言以自动内存管理取代手动分配释放。常见算法包括 mark-sweep、copying、分代回收与并发回收。提前编译场景下还需处理安全点、写屏障与栈映射。

### 中间表示与后端

托管语言的编译器通常从前端经高层中间表示降低到机器码。Midori 的 Bartok 编译器将 MSIL 经高层 IR 再经 Phoenix 后端生成机器码。对单人或小团队项目，不宜自写代码生成器：LLVM 体量巨大，Cranelift 约二十万行，专为正确性与安全设计，由 Wasmtime 采用，更适合独立维护。

### 提前编译

托管语言可解释执行或提前编译（AOT）。AOT 消除运行时编译开销，并支持在无运行时依赖的裸机环境执行。Safe Native Code 详述了 Midori 的 AOT 架构，包括边界检查消除、溢出检查消除、内联与反馈导向优化。

## 值得深入的语言

- **OCaml 与 Standard ML**：类型系统设计的教学样本，也是编写编译器的事实标准。
- **Rust**：在内存安全与操作系统内核这条路上跑通的生产级语言，采用所有权模型而非垃圾回收。
- **Erlang / Elixir**：Actor 模型、分布式容错与运行时隔离的工程参考。
- **Moonbit、Roc、Koka**：新一代语言设计实验，可关注其在效果类型、代数效应等方面的探索。

## 推荐书籍

### 操作系统设计

- 《Operating Systems: Three Easy Pieces》— 理解传统 OS 的虚拟内存、并发、持久化，明确要抛弃哪些部分。
- 《The Design and Implementation of the FreeBSD Operating System》— 看真实 Unix 的完整实现，理解历史包袱的具体形态。
- 《Modern Operating Systems》（Tanenbaum）— 微内核、虚拟化、分布式 OS 的入门视角。
- 《Distributed Systems for Fun and Profit》— 在线小书，分布式视角对现代系统有帮助。
- 《A History of OS/360》— 理解大型系统历史包袱如何形成。
- 《The Soul of a New Machine》— 计算机系统开发的历史与工程文化。
- 《Project Oberon: The Design of an Operating System and Compiler》— Wirth 用一门语言构建系统软件的经典实践。

### 类型系统与编程语言理论

- 《Types and Programming Languages》— 类型系统设计基础。
- 《Advanced Topics in Types and Programming Languages》— 线性类型、依赖类型、效果系统等进阶主题。
- 《Software Foundations》（在线系列）— 形式化证明与类型安全入门。
- 《The Rust Programming Language》— 所有权与内存安全的工程实践。
- 《Rust for Rustaceans》— Rust 高级主题与设计权衡。

### 运行时与内存管理

- 《The Garbage Collection Handbook》— 托管语言与 GC 设计。
- 《Virtual Machines: Versatile Platforms for Systems and Processes》— 语言虚拟机、JIT、系统 VM 的设计思想。
- 《Engine for a Virtual Machine》— 虚拟机实现的深入参考。

### 编译器实现

- 《Engineering a Compiler》— 实现真实语言。
- 《Crafting Interpreters》— 从零写带 GC 的解释器，快速验证语言语义。
- 《Compilers: Principles, Techniques, and Tools》（Dragon Book）— 编译理论经典。
- 《Modern Compiler Implementation in ML》— 函数式风格的编译器实现。

### 能力、隔离与安全

- 《Capability-Based Computer Systems》— 能力系统理论。
- 《Robust Composition》— 能力安全与最小权限设计。
- 《The Art of Computer Systems Security》— 系统安全基础。
- 《A Pragmatic Introduction to Secure Multi-Party Computation》— 多不信任组件共存的思想参考。

## 风险提醒

最大风险不是语言实现，而是**如何在没有硬件 MMU 的情况下保证安全与容错**。软件隔离只在语言正确时成立；编译器 bug、运行时崩溃、非托管代码（驱动 / legacy）都会暴露系统。Midori 和 Singularity 都花大量精力研究信任边界和可验证子集。

## 建议的下一步

1. 精读上述 5 篇核心论文。
2. 用 Crafting Interpreters 或自写最小解释器验证词法 → 解析 → 字节码 → GC 的完整链路。
3. 设计一个最小类型系统，证明或验证它能排除越界访问与非法解引用。
4. 按 `301 编程语言/结构模版.md` 的 10 节结构整理语言设计笔记。
